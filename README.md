# MediaFetch
a lightweight C# tool for fetching playing media


# Usage

```
-title               Get current song title
-artist              Get artist name
-desc                Get title and artist
-status              Get playback status
-time                Get timeline data as json
-art                 Get album art
-all                 Get all data as json
